# ARCHRUUD Overview v1.0.0 — First Stable Release

**Tag:** `overview-v1.0.0`  
**Release title:** `ARCHRUUD Overview v1.0.0`  
**Asset:** `ARCHRUUD-Overview-v1.0.0-GitHub.zip`

ARCHRUUD Overview v1.0.0 brings the proven v0.3 layout to a versioned standalone release for Quickshell and Hyprland Lua.

### Highlights

- Matching ARCHRUUD Desktop styling: a top-centered, dark navy 1260 × 344 px frame with thin blue border and rounded shoulders.
- Ten workspaces in a 5 × 2 layout, with live window previews.
- Open using **CTRL + TAB** or a **left-click in the upper-left screen corner**.
- Focus windows and switch workspaces directly from the overview.
- Self-contained Quickshell module, with install, backup, rollback, uninstall, and English documentation.
- Existing `config.json` and already installed Lua keybinding module preserved during upgrades.

This release repackages the user-tested v0.3 QML files without functional changes.

**Installation:** Download the ZIP, extract it and follow `INSTALL.md`.
